## What shipped

A second binary `uecm-cli` next to the existing Tauri `uecm`, sharing the same `uecm_lib` and the same SQLite database. AI clients and headless users can now drive UECM without the WebView.

### New crate-level pieces

- `src-tauri/src/startup.rs` — shared DB path / DB open + migrate / ps-scripts dir resolvers. `APP_IDENTIFIER = "com.lanbipu.uecm"` pinned to `tauri.conf.json`. Side-effect-free path resolution; directory creation happens lazily in `open_and_migrate_db`.
- `src-tauri/src/cli/` — `args.rs` (clap derive), `output.rs` (object-safe `Emitter` trait + `EmitSerialize` extension trait + `NdjsonEmitter` + `HumanEmitter`), `run.rs` (`Ctx` with `Option<Db>` and `needs_db` gating), `domain_system.rs`, `domain_machine.rs`, `domain_winrm.rs`.
- `src-tauri/src/bin/uecm-cli.rs` — entry point (`Cli::parse() → run::run()`).
- `src-tauri/tests/cli_smoke.rs` — 3 cross-platform integration tests.
- `crate::ENV_TEST_LOCK` — shared mutex serializing env-mutating tests across modules.

### Subcommands

| Domain | Subcommands |
|---|---|
| `system` | `version` / `db-path` / `ps-dir` / `migrate-db` / `echo` |
| `machine` | `list` / `add` / `detail` / `delete` / `rename` / `scan` / `refresh` |
| `winrm` | `probe` / `bootstrap-script` / `bootstrap` |

### Contract decisions enforced

- **NDJSON streaming** — `machine scan` and `machine refresh` emit one event per line (`started` → `host_probe`* / `progress`* → `completed`)
- **Object-safe Emitter** — `EmitSerialize` blanket impl restores ergonomic `emit_result<T>(&value)` on `Box<dyn Emitter>`
- **Lazy DB** — only commands that read/write tables open the DB. `system version` / `db-path` / `ps-dir`, `winrm bootstrap-script`, and even `machine scan` (stateless network probe) run with `Ctx::db = None`
- **UI-compatible status tokens** — `machine refresh` writes `online` / `offline` (not `ok`), matching `commands::discovery::refresh_machine`
- **Idempotent `machine add`** — same IP twice returns `{already_present:true, id, ...}` instead of tripping UNIQUE
- **Refresh by IP** — uses `machine.ip` like the UI, so renamed hostnames don't break WinRM
- **Partial-failure tolerance in refresh** — UE installs persist before GPU detect runs, so a GPU error keeps the UE list
- **Exit codes** — 2 (invalid input) / 3 (environment: DB/IO/configuration) / 4 (PowerShell remote) / 1 (operation failed) / 0 (success)

## Codex adversarial review

Spec went through one upfront adversarial pass; every implementation task triggered a follow-up. Across ~10 review cycles Codex flagged 22 distinct issues — 18 fixed in the same task that introduced them, 1 deferred and later fixed, 3 confirmed false positives (Rust trait-object lifetime elision). No P1/P2 finding shipped unaddressed.

## Out of scope (covered by future plans)

- SIGINT / Ctrl-C graceful cancel
- Credential-aware `machine refresh` (needs `core::winrm::probe_with_credential` + `detect_*_with_credential`)
- Shell completion / daemon mode / MCP wrapper
