## What shipped

Plan 3 ships the remaining 5 CLI domains plus closes Plan 1's deferred
machine-refresh credential support. Combined with Plans 1 + 2, all 12
UECM domains are now reachable from `uecm-cli`:

| Domain | Status |
|---|---|
| system / machine / winrm | ✅ Plan 1 |
| cred / env / ini (single-key) / share | ✅ Plan 2 |
| project / health / gpu / ddc / pso + ini (cluster scan) | ✅ Plan 3 (this) |
| machine refresh with --cred-alias / --user --pass | ✅ Plan 3 (Plan-1 deferred closed) |

### New core fns

- `core::winrm::probe_with_credential`
- `core::discovery::detect_ue_versions_with_credential`
- `core::discovery::detect_gpus_with_credential`

Three thin wrappers using existing `invoke_*_with_credential`.

### New CLI domains

- **project** — list / locations / discover / create-manual / set-location / delete / delete-location
- **ini** (cluster) — scan (NDJSON stream) / runs / findings / get-finding / apply / skip / verify-pso-precaching
- **health** — run (NDJSON stream) / runs / results
- **gpu** — matrix
- **ddc** — generate (UE runner NDJSON stream) / verify / distribute (per-target NDJSON)
- **pso** — verify / collect (UE runner stream) / list / distribute (per-target with GPU mismatch guard)

### UE runner stream contract

`ddc generate` and `pso collect` forward `core::ue_runner::UeRunnerEvent` enum to
NDJSON one-for-one: `spawned` → `log_line` × N → `progress` × N → `completed`.
CLI process uses `tokio::runtime::Builder::new_current_thread()` to drain the
mpsc receiver synchronously.
