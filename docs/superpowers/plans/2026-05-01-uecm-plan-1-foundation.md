# UECM Plan 1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the foundational scaffolding of UE Cache Manager (UECM): a Tauri 2.x desktop app with Vue 3 frontend, Rust backend, SQLite persistence, PowerShell sidecar invocation, and 7 navigable view stubs ready for feature implementation in subsequent plans.

**Architecture:** Tauri 2.x cross-platform desktop framework. Vue 3 frontend (Composition API + `<script setup>`) with Tailwind CSS, Pinia state management, Vue Router. Rust backend with rusqlite for SQLite, tokio async runtime, structured error handling. Frontend ↔ backend bridge via Tauri commands. Windows-specific code (PowerShell sidecar, future WinRM/registry) wrapped in `#[cfg(windows)]` so non-Windows dev environments can still build & test the platform-agnostic core.

**Tech Stack:** Rust 1.75+, Tauri 2.x, rusqlite (bundled SQLite), tokio, serde, thiserror. Vue 3, Vite, TypeScript, Tailwind CSS 3, Pinia, Vue Router, Vitest, @vue/test-utils. pnpm package manager.

**Out of scope for this plan (deferred to later plans):** Network discovery, WinRM client, UE detection, GPU detection, credential management, INI editing, env var configuration, all wizards, INI scanner, health check, DDC Pak, PSO Cache, visual design polish.

**Deliverable at end:** A Tauri app named `UECM` that launches into a windowed app showing 7 navigable view stubs (Dashboard / Machines / Projects / DDC Pak / PSO Cache / INI Scanner / Health Check), with a working SQLite persistence layer, a working PowerShell sidecar bridge demonstrated by a "test echo" script, and a green test suite. Buildable to a single `.exe`.

**Reasoning for file split:**
- `src-tauri/src/commands/`: thin command handlers — translate Tauri invoke calls to core function calls. Keep small, no business logic.
- `src-tauri/src/core/`: business logic, platform-specific helpers (PowerShell sidecar today; WinRM client + registry queries in Plan 2).
- `src-tauri/src/data/`: SQLite schema + CRUD. Each file = one logical entity (machines today; projects/configs/etc. in later plans).
- `src/views/`: one file per top-level route — keeps each view self-contained.
- `src/services/tauri.ts`: single typed wrapper around `invoke()` — frontend never calls `invoke()` directly, all goes through this for type safety + easier mocking in tests.
- `src/stores/`: Pinia stores — one per logical entity. Centralizes state + Tauri call orchestration.

## Prerequisites (engineer must have installed before starting)

- **Rust toolchain**: Rust 1.75+ via rustup (`https://rustup.rs/`)
- **Node.js**: 20.x or later
- **pnpm**: `npm install -g pnpm` (we use pnpm, not npm)
- **OS-specific Tauri prerequisites**: see https://v2.tauri.app/start/prerequisites/
  - macOS: Xcode Command Line Tools
  - Windows: Microsoft C++ Build Tools + WebView2 (preinstalled on Win10/11)
  - Linux: `webkit2gtk` etc.
- **Tauri CLI**: installed per-project via dev dependency (Task 3 handles this)

**Development OS note:** This tool ultimately targets Windows only. However, the foundation in this Plan 1 is platform-agnostic — Mac/Linux developers can build, run dev mode, and run the test suite. PowerShell sidecar invocation will fail outside Windows; the relevant test marks itself as `#[cfg(windows)]` so it's skipped. Plans 2+ add more Windows-specific code; recommend developing on a Windows machine from Plan 2 onward.

        let code = match &err {

            UecmError::PowerShell(_) => "POWERSHELL",

//! Database schema migrations. Runs idempotently on app startup.
//! Each migration is wrapped in a transaction.

use crate::error::UecmResult;
use rusqlite::Connection;

const MIGRATIONS: &[(&str, &str)] = &[
    (
        "001_machines_table",
        r#"
        CREATE TABLE IF NOT EXISTS machines (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            hostname TEXT NOT NULL,
            ip TEXT NOT NULL UNIQUE,
            role TEXT NOT NULL DEFAULT 'unknown',
            status TEXT NOT NULL DEFAULT 'unknown',
            last_seen_at TEXT,
            created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        );
        CREATE INDEX IF NOT EXISTS idx_machines_status ON machines(status);
        "#,
    ),
    (
        "002_migrations_table",
        r#"
        CREATE TABLE IF NOT EXISTS schema_migrations (
            name TEXT PRIMARY KEY,
            applied_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        );
        "#,
    ),
];

pub fn migrate(conn: &mut Connection) -> UecmResult<()> {
    // Bootstrap: ensure migrations table exists.
    conn.execute(
        "CREATE TABLE IF NOT EXISTS schema_migrations (
            name TEXT PRIMARY KEY,
            applied_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        )",
        [],
    )?;

    for (name, sql) in MIGRATIONS {
        let already_applied: bool = conn
            .query_row(
                "SELECT 1 FROM schema_migrations WHERE name = ?",
                [name],
                |_| Ok(true),
            )
            .unwrap_or(false);

        if already_applied {
            continue;
        }

        let tx = conn.transaction()?;
        tx.execute_batch(sql)?;
        tx.execute(
            "INSERT INTO schema_migrations (name) VALUES (?)",
            [name],
        )?;
        tx.commit()?;
        tracing::info!("applied migration: {}", name);
    }

    Ok(())
}

//! PowerShell sidecar invocation. On Windows, runs powershell.exe with
//! provided script + args, captures stdout, returns parsed JSON result.
//! On non-Windows, returns an error (sidecar is Windows-only).

use crate::error::{UecmError, UecmResult};
use serde::de::DeserializeOwned;
use std::path::Path;
use std::process::Command;

#[derive(Debug)]
pub struct ScriptResult {
    pub stdout: String,
    pub stderr: String,
    pub exit_code: i32,
}

/// Run a .ps1 script with the given arguments. Returns raw output.
pub fn run_script(script_path: &Path, args: &[&str]) -> UecmResult<ScriptResult> {
    #[cfg(windows)]
    {
        let mut cmd = Command::new("powershell.exe");
        cmd.arg("-NoProfile")
            .arg("-ExecutionPolicy")
            .arg("Bypass")
            .arg("-File")
            .arg(script_path);
        for arg in args {
            cmd.arg(arg);
        }
        let output = cmd.output().map_err(|e| {
            UecmError::PowerShell(format!("failed to spawn powershell.exe: {}", e))
        })?;
        Ok(ScriptResult {
            stdout: String::from_utf8_lossy(&output.stdout).to_string(),
            stderr: String::from_utf8_lossy(&output.stderr).to_string(),
            exit_code: output.status.code().unwrap_or(-1),
        })
    }
    #[cfg(not(windows))]
    {
        let _ = (script_path, args);
        Err(UecmError::PowerShell(
            "PowerShell sidecar is Windows-only".to_string(),
        ))
    }
}

/// Run a script and parse stdout as JSON of type T.
pub fn run_json<T: DeserializeOwned>(script_path: &Path, args: &[&str]) -> UecmResult<T> {
    let result = run_script(script_path, args)?;
    if result.exit_code != 0 {
        return Err(UecmError::PowerShell(format!(
            "script exited with code {}: {}",
            result.exit_code, result.stderr
        )));
    }
    serde_json::from_str(&result.stdout).map_err(|e| {
        UecmError::PowerShell(format!("failed to parse JSON output: {} (stdout: {})", e, result.stdout))
    })
}

export interface Machine {

import { defineStore } from "pinia";
import { ref } from "vue";
import { tauriApi, type Machine, type UecmError } from "@/services/tauri";

export const useMachinesStore = defineStore("machines", () => {
  const machines = ref<Machine[]>([]);
  const isLoading = ref(false);
  const error = ref<UecmError | null>(null);

  async function loadMachines() {
    isLoading.value = true;
    error.value = null;
    try {
      machines.value = await tauriApi.listMachines();
    } catch (e) {
      error.value = e as UecmError;
    } finally {
      isLoading.value = false;
    }
  }

  async function addMachine(hostname: string, ip: string) {
    error.value = null;
    try {
      await tauriApi.addMachine(hostname, ip);
      await loadMachines();
    } catch (e) {
      error.value = e as UecmError;
    }
  }

  async function deleteMachine(id: number) {
    error.value = null;
    try {
      await tauriApi.deleteMachine(id);
      await loadMachines();
    } catch (e) {
      error.value = e as UecmError;
    }
  }

  return {
    machines,
    isLoading,
    error,
    loadMachines,
    addMachine,
    deleteMachine,
  };
});
